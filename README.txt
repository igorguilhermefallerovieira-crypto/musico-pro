MÚSICO PRO — PRIMEIRA VERSÃO (PROTÓTIPO)

O que já funciona:
- Adicionar e editar músicas com letra/cifras, artista, tom e repertório.
- Busca, favoritos e navegação entre músicas.
- Rolagem manual e automática com velocidade ajustável.
- Aumentar/diminuir fonte.
- Transposição básica de acordes.
- Importar TXT, PRO, CHO, ChordPro, PDFs e arquivos de áudio pequenos.
- Reproduzir áudio anexado quando o navegador suporta.
- Backup e importação de backup JSON.
- Armazenamento local e modo offline após a primeira abertura em hospedagem HTTPS.

IMPORTANTE:
- Esta é uma primeira versão web instalável (PWA), não um APK nativo ainda.
- A sincronização na nuvem ainda não foi implementada.
- Anexos são limitados a 3 MB para reduzir risco de lotar o armazenamento do navegador.
- PDFs são anexados e abertos externamente; o leitor de PDF não tem rolagem automática nesta versão.
- Faça backups regulares. Limpar os dados do navegador pode apagar a biblioteca local.

PARA TESTAR NO ANDROID:
1. Publique estes arquivos em uma hospedagem HTTPS, por exemplo GitHub Pages.
2. Abra o endereço no Chrome do Android.
3. Menu ⋮ > "Adicionar à tela inicial" ou "Instalar app".
4. Abra o ícone instalado e teste offline depois de carregar uma vez.

PRÓXIMA ETAPA:
Conectar sincronização de nuvem com autenticação e armazenamento seguro, preservando os arquivos locais e tratando conflitos de edição.
